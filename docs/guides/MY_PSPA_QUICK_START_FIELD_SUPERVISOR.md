# Quick Start Pembimbing Lapangan MY PSPA

## Login dan Role

Masuk memakai akun Core Farmasi, lalu pilih role Pembimbing Lapangan. Jika role tidak tersedia, hubungi Koordinator PKPA atau tim pengelola Core.

## Menu Utama

- Jadwal PKPA: mahasiswa yang ditempatkan di tempat praktik.
- Operasional PKPA: presensi, logbook, dan progress rotasi.
- Akademik Rotasi: kompetensi, tugas, laporan, dan review lapangan.
- Penilaian: input atau review nilai sesuai skema yang berlaku.

## Alur Kerja

1. Cek mahasiswa dan periode rotasi.
2. Validasi presensi sesuai kehadiran nyata.
3. Review logbook dan beri komentar bila perlu.
4. Verifikasi capaian kompetensi atau tugas sesuai kewenangan.
5. Laporkan kendala operasional ke Koordinator PKPA.

## Batasan Akses

- Hanya akses mahasiswa yang ditugaskan pada tempat praktik terkait.
- Jangan membagikan dokumen mahasiswa di luar kanal resmi.
- Jangan mengirim password, token, atau data sensitif melalui tiket bantuan.

## Error Umum

- Mahasiswa tidak tampil: publikasi jadwal belum current atau mapping tempat-pembimbing belum lengkap.
- Presensi tidak bisa divalidasi: status rotasi belum aktif atau periode tidak sesuai.
- File gagal dibuka: file belum tersedia atau akses tidak terkait.
