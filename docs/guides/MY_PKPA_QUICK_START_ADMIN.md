# Quick Start Admin MY PKPA

## Status Rilis

- Human UAT: Waived by Project Owner
- Release approach: Controlled Go-Live
- Post-release mode: Intensive Hypercare

## Login dan Role

1. Buka URL MY PKPA yang diberikan tim IT.
2. Masuk memakai akun Core Farmasi.
3. Pilih role Admin jika akun memiliki lebih dari satu role.
4. Logout setelah selesai memakai komputer bersama.

Jangan membagikan password atau OTP. Jika login gagal, cek status akun di Core Farmasi melalui tim pengelola akun.

## Menu Utama

- Dashboard: ringkasan status PKPA.
- Master PKPA: program, wahana, tempat praktik, dan konfigurasi.
- Peserta PKPA: kepesertaan, import, dan requirement.
- Dokumen PKPA: template, penomoran, generasi, distribusi, dan audit.
- Analytics: rekap operasional dan akademik.
- Health admin: pemeriksaan kondisi sistem bila tersedia untuk role.

## Alur Harian

1. Pastikan program PKPA aktif dan konfigurasi lengkap.
2. Periksa data peserta dan requirement enam wahana.
3. Pantau readiness penempatan dan publikasi.
4. Pantau dokumen, queue, dan laporan error.
5. Catat temuan hypercare pada `docs/hypercare/MY_PKPA_HYPERCARE_LOG.md`.

## Error Umum

- Login ditolak: akun Core tidak aktif, role tidak diberi akses aplikasi, atau Core tidak reachable.
- Halaman 403: role aktif tidak berhak mengakses menu.
- File gagal diunduh: dokumen belum tersedia, file tidak ada, atau akses tidak sesuai role.
- Queue/dokumen lambat: cek status queue dan hubungi tim IT.

## Kontak Bantuan

Gunakan kanal bantuan internal yang ditetapkan Project Owner atau tim IT. Jangan mengirim password, token, atau data pribadi berlebihan dalam tiket.
