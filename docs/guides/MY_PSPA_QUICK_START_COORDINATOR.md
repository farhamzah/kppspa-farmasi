# Quick Start Koordinator PKPA MY PSPA

## Status Rilis

- Human UAT: Waived by Project Owner
- Release approach: Controlled Go-Live
- Post-release mode: Intensive Hypercare

## Login dan Role

Masuk memakai akun Core Farmasi, lalu pilih role Koordinator PKPA. Jika role tidak muncul, minta tim pengelola Core memeriksa application access dan assignment role.

## Menu Utama

- Readiness PKPA: cek kesiapan program, tempat, kapasitas, dan pembimbing.
- Penyusun Penempatan: susun draft rotasi, validasi konflik, dan kunci plan.
- Publikasi Penempatan: publish jadwal resmi setelah plan valid.
- Operasional Rotasi: pantau presensi, logbook, progress, dan perubahan.
- Penilaian dan Nilai Akhir: finalisasi nilai sesuai policy akademik.
- Dokumen dan Analytics: generate dokumen internal dan pantau rekap.

## Alur Utama

1. Pastikan master program dan enam wahana lengkap.
2. Pastikan peserta, kelompok, tempat, kapasitas, dan pembimbing valid.
3. Susun draft penempatan, jalankan validasi, lalu kunci plan.
4. Publish jadwal resmi hanya setelah siap.
5. Pantau rotasi berjalan, presensi, logbook, kompetensi, laporan, nilai, dan dokumen.

## Keamanan dan Kontrol

- Jangan mengubah formula akademik selama release freeze tanpa approval.
- Jangan membuat akun atau role lokal untuk mengganti Core Farmasi.
- Jangan menjalankan perubahan data massal tanpa preview dan catatan.
- Gunakan incident matrix untuk temuan P0/P1.

## Error Umum

- Plan tidak bisa publish: masih ada error validasi atau plan belum locked.
- Pembimbing tidak muncul: eligibility atau mapping Core belum lengkap.
- Nilai tidak bisa final: readiness, komponen, atau policy belum terpenuhi.
