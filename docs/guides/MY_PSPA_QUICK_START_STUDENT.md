# Quick Start Mahasiswa MY PSPA

## Login dan Role

1. Buka URL MY PSPA.
2. Masuk memakai akun Core Farmasi.
3. Pilih role Mahasiswa jika diminta.
4. Pastikan nama dan program PKPA benar.

Jangan membagikan password. Jika akun tidak aktif atau role tidak tersedia, hubungi admin akademik atau tim IT.

## Menu Utama

- Dashboard: ringkasan PKPA Anda.
- PKPA Saya atau Jadwal PKPA: jadwal dan penempatan yang sudah dipublikasikan.
- Rotasi PKPA: presensi, logbook, kompetensi, tugas, laporan, dan progress.
- Dokumen: dokumen internal yang berhak Anda lihat.
- Nilai: nilai yang sudah dirilis sesuai kebijakan.

## Alur Harian

1. Cek jadwal rotasi dan tempat praktik.
2. Isi presensi dan logbook sesuai aturan program.
3. Unggah bukti, tugas, atau laporan hanya pada menu resmi.
4. Pantau feedback pembimbing dan perbaiki bila diminta.
5. Logout setelah selesai.

## Error Umum

- Jadwal belum tampil: jadwal belum dipublikasikan atau Anda belum menjadi peserta program.
- Upload gagal: ukuran atau tipe file tidak sesuai.
- Nilai belum tampil: nilai belum dirilis.
- Akses ditolak: role aktif bukan Mahasiswa atau data bukan milik Anda.

## Bantuan

Laporkan masalah dengan menyebut menu, waktu kejadian, dan tangkapan layar bila perlu. Jangan kirim password atau token.
