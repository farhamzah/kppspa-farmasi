# Quick Start Pembimbing Dalam MY PKPA

## Login dan Role

Masuk memakai akun Core Farmasi, lalu pilih role Pembimbing Dalam. Role dan akses berasal dari Core Farmasi dan eligibility program.

## Menu Utama

- Dashboard: ringkasan mahasiswa bimbingan.
- Monitoring PKPA: jadwal, progress, presensi, dan logbook mahasiswa.
- Akademik PKPA: kompetensi, tugas, laporan, dan bimbingan.
- Penilaian: review atau input sesuai hak dan workflow.
- Dokumen: dokumen internal terkait bimbingan.

## Alur Kerja

1. Cek daftar mahasiswa bimbingan dan rotasi aktif.
2. Pantau logbook dan progress.
3. Beri komentar akademik sesuai kebutuhan.
4. Review laporan atau readiness akademik bila menjadi kewenangan.
5. Catat masalah operasional ke Koordinator PKPA.

## Batasan Akses

- Pembimbing Dalam hanya melihat mahasiswa yang terkait assignment atau eligibility.
- Pembimbing Dalam tidak menggantikan validasi presensi Pembimbing Lapangan kecuali workflow resmi berubah.
- Data nilai dan kelulusan mengikuti release akademik.

## Error Umum

- Mahasiswa tidak muncul: assignment pembimbing belum dipublikasikan atau eligibility belum sinkron.
- File tidak bisa dibuka: akses tidak terkait atau file belum tersedia.
- Menu tidak lengkap: role Core belum sesuai.
