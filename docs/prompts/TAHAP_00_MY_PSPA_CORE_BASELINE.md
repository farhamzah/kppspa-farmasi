# Prompt Tahap 00 MY PSPA Core Baseline

Instruksi tahap ini meminta baseline workspace, audit Core Farmasi, audit MY PSPA, rebranding ke MY PSPA, landing page publik, integrasi autentikasi dan role dengan Core, penonaktifan registrasi/reset/password/role lokal, penonaktifan war, dokumentasi migrasi domain PKPA, spesifikasi UX penempatan, test, dan QA tanpa commit/push/release.

Tahap berikutnya yang direkomendasikan setelah acceptance: Tahap 01 - Master Program PKPA, Enam Wahana Default, Pilihan Pemerintahan, Tempat Praktik, dan Konfigurasi Durasi dengan Referensi User dari Core Farmasi.
