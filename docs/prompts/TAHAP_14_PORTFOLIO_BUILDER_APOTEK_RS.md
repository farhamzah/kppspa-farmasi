# TAHAP 14 - Pembuat Portofolio Digital PKPA Wahana Apotek dan Rumah Sakit

Bangun Pembuat Portofolio generik per program dan wahana, pola awal Apotek dan Rumah Sakit, portofolio otomatis per rotasi berjalan, bagian manual terstruktur, alur pemeriksaan PL/PD, daftar kelengkapan, versi, kunci, penerbitan, unduhan DOCX/PDF privat, validasi privasi pasien, tampilan per peran, pengujian, dan dokumentasi.

Jangan mengubah `apps/core-farmasi`. Jangan membuat template Puskesmas, PBF, Industri, atau Pemerintahan pada tahap ini. Jangan commit/push tanpa izin eksplisit Manajer Proyek.
