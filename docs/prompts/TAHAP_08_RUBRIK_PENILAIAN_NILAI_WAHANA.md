# TAHAP 08 - Rubrik Penilaian, Moderasi, dan Nilai Wahana

Implementasi dilakukan pada `apps/kppspa-farmasi` tanpa mengubah `apps/core-farmasi`.

Lingkup:

- assessment scheme per program domain;
- komponen dan bobot;
- rubrik/kriteria/level;
- assessment instance per rotation run;
- assessor assignment dari supervisor aktif;
- component score;
- completion check;
- moderation;
- grade result per wahana;
- release nilai;
- grade change request;
- UI role dan export.

Non-lingkup:

- nilai akhir keseluruhan PKPA;
- huruf mutu akhir;
- yudisium;
- sertifikat;
- integrasi SIAKAD/PDDikti;
- perubahan legacy `kp_*`.
