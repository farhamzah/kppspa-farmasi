# MY PSPA Placement UI/UX Spec

## Matriks

Desktop memakai matriks mahasiswa x enam wahana dengan sticky header, sticky kolom mahasiswa, dan scroll horizontal hanya pada container matriks. Setiap sel menampilkan status teks, tempat, tanggal, PD, PL, dan form simpan eksplisit.

## Mobile

Mobile memakai kartu mahasiswa. Setiap kartu memuat enam wahana dan form sel yang sama. Aksi massal tetap tersedia, tetapi fokus utama mobile adalah edit individual.

## Bulk

Panel bulk memilih mahasiswa, wahana, tempat, availability, tanggal, PD, PL, mode overwrite, lalu membuat preview. Apply baru tersedia setelah preview.

## Validasi

Issue list berada di samping matriks dan setiap issue mengarah ke sel requirement terkait. Warna selalu disertai teks status.

## Bahasa

Antarmuka memakai Bahasa Indonesia. Istilah asing hanya dipakai bila umum di sistem teknis, seperti `bulk`, `draft`, `current`, dan `export`.
