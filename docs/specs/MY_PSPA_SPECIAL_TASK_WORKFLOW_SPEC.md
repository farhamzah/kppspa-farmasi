# MY PSPA Special Task Workflow Spec

Tugas khusus memakai template aktif per program-wahana dan ditugaskan ke runtime rotasi secara idempotent.

## Alur

1. Admin/Koordinator membuat template tugas.
2. Admin/Koordinator membuat assignment tugas dari template.
3. Mahasiswa mengunggah submission berversi.
4. Reviewer yang diwajibkan memberi approval, revision request, atau rejection.

Approval tugas bukan nilai dan tidak menghitung bobot.
