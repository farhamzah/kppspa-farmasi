# MY PSPA Requirement Completion Spec

Requirement wahana hanya dapat completed setelah runtime operational complete, academic readiness `ready_for_assessment`, grade result wahana finalized/released, tidak ada remedial aktif, dan jika minimum score dikonfigurasi maka nilai memenuhi minimum tersebut.

Completion eksplisit dilakukan Koordinator. Reopen wajib alasan dan tidak menghapus histori completion.
