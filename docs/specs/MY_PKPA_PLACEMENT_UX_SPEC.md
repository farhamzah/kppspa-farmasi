# MY PKPA Placement UX Spec

## Prinsip

Penempatan dibuat oleh Koordinator PKPA. Mahasiswa tidak memilih tempat, tidak mengunci kuota, dan tidak memakai first come first served.

## Matriks Utama

Baris: mahasiswa.

Kolom:

- Apotek
- Puskesmas
- PBF
- Rumah Sakit
- Industri
- Pemerintahan

Setiap sel menampilkan tempat, tanggal, pembimbing dalam, pembimbing lapangan, status, dan konflik.

## Drawer Cepat

Klik sel membuka drawer berisi mahasiswa, wahana, subjenis Pemerintahan, tempat, tanggal mulai, tanggal selesai, durasi, pembimbing dalam dari Core, pembimbing lapangan dari Core, kelompok, dan catatan.

## Penempatan Massal

Alur: pilih mahasiswa, pilih wahana, pilih tempat, pilih tanggal, pilih pembimbing, preview, validasi, terapkan, undo.

## Tampilan Tambahan

- Kalender
- Timeline
- Kapasitas tempat
- Beban pembimbing
- Konflik
- Kelengkapan enam wahana
- Import Excel
- Preview import
- Publikasi
- Riwayat

Dropdown pembimbing wajib memakai data Core dan tidak membuat akun baru.
