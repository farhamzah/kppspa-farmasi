# MY PKPA Guidance Workflow Spec

Bimbingan rotasi dicatat di `pkpa_rotation_guidance_sessions`.

## Aturan

- Pembimbing Dalam atau Preseptor aktif dapat mencatat bimbingan sesuai hak runtime.
- Mahasiswa hanya dapat melihat dan acknowledge bimbingan miliknya.
- Acknowledgement adalah tanda membaca, bukan approval.
- Catatan pembimbing tidak dapat diubah mahasiswa.
