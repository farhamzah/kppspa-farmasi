# MY PKPA Academic Readiness Spec

Academic readiness memeriksa apakah rotasi siap masuk tahap penilaian.

## Checklist

- Operasional rotasi sudah complete.
- Kompetensi wajib sudah verified.
- Tidak ada kompetensi revision requested.
- Tugas wajib sudah approved.
- Laporan rotasi sudah approved jika tersedia.

Status `ready_for_assessment` bukan nilai, bukan kelulusan, dan tidak mengubah requirement menjadi `completed`.
