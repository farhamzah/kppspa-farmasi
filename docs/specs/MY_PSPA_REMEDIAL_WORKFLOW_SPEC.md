# MY PSPA Remedial Workflow Spec

Remedial disimpan sebagai policy, case, dan attempt. Kasus remedial tidak menghapus nilai awal. Attempt menyimpan selected score dan alasan bila policy membutuhkan pemilihan Koordinator.
